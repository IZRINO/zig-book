关于本书

这是一本面向 Zig 编程语言 的开源、偏实战的技术入门读物。作为一门现代化通用底层语言，Zig 的设计初衷就是为了写出运行极致优化、运行状态稳定可靠的高质量软件。

本书英文原版官方仓库：https://github.com/pedropark99/zig-book。

无论是新手小白还是资深老手，读这本书都会有所收获。本书最大的特点是拒绝枯燥的语法死记硬背，而是像经典的《Python 编程：从入门到实践》（Eric Matthes 著）一样，手把手通过写真实小项目带大家玩转 Zig。 书中实战涵盖了：从零实现 Base64 编解码器、手写轻量 HTTP 服务器、开发图像滤镜等一系列趣味与硬核兼备的项目。

跟着整本书敲下来，你会掌握：

  • Zig 语法全貌，以及它与 C、C++、Rust 的设计哲学对比。
  • 常用数据结构、底层内存分配器（Allocator）、文件系统与 I/O 操作。
  • 可选类型（Optionals）——告别空指针异常的现代化空值处理新范式。
  • 如何编写测试用例与在实际开发中高效调试 Zig 程序。
  • 作为一等公民的值类型错误体系（Errors as values）及其优雅处理姿势。
  • 使用 Zig 语言内置的原生构建系统（Build System）编译 C 与 Zig 项目。
  • Zig 与 C 语言的丝滑互操作（C Interop）。
  • 线程并发与 SIMD 向量化并行加速。
  • 以及更多底层系统开发的实战技巧。
